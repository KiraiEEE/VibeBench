==============================================================================
 2. AFTER PYTHON V2: what it is actually for
==============================================================================

Python V2 exists to answer ONE question the Java thesis explicitly could not:

  Is the per-agent ordering a property of the AGENTS, or of how they write
  JAVA?

The Java thesis says, in the joint model, that change size dominates every
principle (odds ratio 1.9 per doubling of files touched) and that only
Open/Closed survives adjustment (Claude Code 2.22, 1.21 to 4.07, p 0.010).
Chapter 5 names a second language with the same agent coverage as the way to
test whether that generalises. Python V2 is that test.

So when Python results exist and are validated, the comparisons to make are:

  1. Does change size still dominate, at a similar odds ratio?
     If yes, that is a strong cross-language result and the single most
     valuable finding available to this work.
  2. Does the Open/Closed agent effect reproduce, or was it Java-specific?
  3. Is risk still intra-unit rather than inter-unit? Java found ~4,100 SRP
     violations present but agents introducing one in only 2 to 4 per cent of
     requests, and 681 refused-bequest relationships present against 16
     introduced.
  4. Does the categorical-versus-numeric refinement lesson repeat? In Java the
     categorical rule (refused bequest) held at 1.000 on a holdout while the
     numeric threshold (>=30 members) fell from 0.862 to 0.704.

ONLY THEN touch the thesis. Until Python results exist AND are validated, the
thesis is a correct, complete, Java-only document and must stay that way. When
they do exist, it becomes a two-language study and the title, abstract, RQs and
Chapter 5 all need revisiting, not just a new results section.

Optional, lower value than the above: LSP and ISP weighted recall rest on few
observations in the unflagged stratum, so their intervals are wide. A sample
drawn ONLY from unflagged entities would narrow them. The three Java misses say
where to look: silent refusals, not declared ones (an empty override body, a
setter that discards its argument, a precondition strengthened by throwing).
