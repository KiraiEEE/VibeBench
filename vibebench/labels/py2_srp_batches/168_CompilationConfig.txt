      360

      376      - CudaGraph capture:
      377          - [`cudagraph_mode`][vllm.config.CompilationConfig.cudagraph_mode]
      378          - [`cudagraph_capture_sizes`]
      379          [vllm.config.CompilationConfig.cudagraph_capture_sizes]

      383          [vllm.config.CompilationConfig.cudagraph_num_of_warmups]
      384          - [`cudagraph_copy_inputs`]

      387          - [`compile_sizes`][vllm.config.CompilationConfig.compile_sizes]

      389              [vllm.config.CompilationConfig.compile_ranges_endpoints]

      391          [vllm.config.CompilationConfig.inductor_compile_config]
      392          - [`inductor_passes`][vllm.config.CompilationConfig.inductor_passes]
      393          - custom inductor passes
      394  
      395      Why we have different sizes for cudagraph and inductor:
      396      - cudagraph: a cudagraph captured for a specific size can only be used
      397          for the same size. We need to capture all the sizes we want to use.
      398      - inductor: a graph compiled by inductor for a general shape can be used
      399          for different sizes. Inductor can also compile for specific sizes,
      400          where it can have more information to optimize the graph with fully
      401          static shapes. However, we find the general shape compilation is
      402          sufficient for most cases. It might be beneficial to compile for
      403          certain small batchsizes, where inductor is good at optimizing.
      404      """

      525      cudagraph_mode: CUDAGraphMode = Field(default=None)
      526      """
      527      The mode of the cudagraph:
      528  
      529      - NONE, no cudagraph capture.
      530      - PIECEWISE.
      531      - FULL.
      532      - FULL_DECODE_ONLY.
      533      - FULL_AND_PIECEWISE. (v1 default)
      534  
      535      PIECEWISE mode build piecewise cudagraph only, keeping the cudagraph
      536      incompatible ops (i.e. some attention ops) outside the cudagraph
      537      for general flexibility.
      538  
      539      FULL mode: Capture full cudagraph for all batches. Can be good for small
      540      models or workloads with small prompts; not supported by many backends.
      541      Generally for performance FULL_AND_PIECEWISE is better.
      542  
      543      FULL_DECODE_ONLY mode: Capture full cudagraph for decode batches only.
      544      Mixed prefill-decode batches are run without cudagraphs. Can be good for
      545      decode instances in a P/D setup where prefill is not as important so we
      546      can save some memory.
      547  
      548      FULL_AND_PIECEWISE mode: Capture full cudagraph for decode batches and
      549      piecewise cudagraph for prefill and mixed prefill-decode batches.
      550      This is the most performant mode for most models and is the default.
      551  
      552      Currently, the cudagraph mode is only used for the v1 engine.
      553      Note that the cudagraph logic is generally orthogonal to the
      554      compilation logic. While piecewise cudagraphs require piecewise
      555      compilation (mode=VLLM_COMPILE and non-empty splitting_ops), full
      556      cudagraphs are supported with and without compilation.
      557  
      558      Warning: This flag is new and subject to change in addition
      559      more modes may be added.

      587      use_inductor_graph_partition: bool = Field(default=None)
      588      """Use inductor graph partition to split the graph at cudagraph_unsafe ops.
      589      This partition happens at inductor codegen time after all passes and fusions
      590      are finished. It generates a single `call` function which wraps
      591      cudagraph-safe ops into partition functions and leave cudagraph-unsafe ops
      592      outside the partition functions. For a graph with N cudagraph-unsafe ops
      593      (e.g., Attention), there would be N+1 partitions. To mark an op as
      594      cudagraph unsafe, we can add `tags=(torch._C.Tag.cudagraph_unsafe)` when
      595      register the custom op.
      596  
      597      This config supports both full cudagraph and piecewise cudagraph without
      598      compiling twice. For piecewise cudagraph, it applies vLLM CUDAGraph wrapper
      599      to each partition. For N+1 partitions, there would be N+1
      600      CUDAGraph wrapper instances.
      601  
      602      For full CUDAGraph, we always apply a single CUDAGraph wrapper outside the
      603      inductor `call` function in the model runner. The top-level full cudagraph
      604      capture ignores all partitioning.

      697      def compute_hash(self) -> str:
      698          """
      699          Provide a hash that uniquely identifies all the configs
      700          that affect the structure of the computation
      701          graph from input ids/embeddings to the final hidden states,
      702          excluding anything before input ids/embeddings and after
      703          the final hidden states.
      704          """
      705          # Opt-out: default-include declared fields; keep a tiny exclude set;
      706          # normalize types; keep SHA-256. For nested opaque configs, include a
      707          # stable identifier (e.g., pass_config.compute_hash()) instead of object id.
      708  
      709          ignored_factors = {
      710              # Paths/dirs and runtime/metrics that don’t affect compiled graph
      711              "debug_dump_path",
      712              "cache_dir",
      713              "local_cache_dir",
      714              "traced_files",
      715              "compilation_time",
      716              "static_forward_context",
      717              "pass_config",  # handled separately below
      718              "dynamic_shapes_config",  # handled separately below
      719          }
      720  
      721          from vllm.config.utils import get_hash_factors, hash_factors
      722  
      723          factors = get_hash_factors(self, ignored_factors)
      724  
      725          factors["pass_config"] = self.pass_config.compute_hash()
      726          factors["dynamic_shapes_config"] = self.dynamic_shapes_config.compute_hash()
      727          return hash_factors(factors)
