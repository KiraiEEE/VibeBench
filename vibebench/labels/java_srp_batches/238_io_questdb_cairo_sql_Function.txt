       65      /**
       66       * Initializes each function in the list of clones. It is assumed by this method that "clones" are copies of
       67       * the same function.
       68       * <p>
       69       * Two-phase functions might need to perform certain transformations upfront, before SQL executes. This is to
       70       * avoid doing those transformations on for every row/invocation. These transformations are done during the
       71       * "init" phase.
       72       * <p>
       73       * During concurrent SQL execution it might be beneficial to split the "init" phase into per-SQL execution and
       74       * per-thread. For example "init" could be a heavy SQL execution itself, which would benefit from executing once and
       75       * copying state of this execution to clones, so that clones to not have to repeat that heavy SQL execution. The
       76       * "prototype" function is the one that has already been fully initialized, and it is ready to pass its state to
       77       * all the clones.
       78       * <p>
       79       * Even though the prototype will be trying to pass its state, the clones do not have to accept it and choose to
       80       * continue to calculate own state.
       81       *
       82       * @param clones            uniform function to initialize and accept state from the prototype, if prototype is not null
       83       * @param symbolTableSource symbol table source to perform symbol value to key conversion
       84       * @param executionContext  the execution context, bind variables etc
       85       * @param prototypeFunction the prototype function, ready to donate its state
       86       * @throws SqlException function are allowed to throw SQLException to indicate initialization error
       87       */
       88      static void init(
       89              ObjList<? extends Function> clones,
       90              SymbolTableSource symbolTableSource,
       91              SqlExecutionContext executionContext,
       92              @Nullable Function prototypeFunction
       93      ) throws SqlException {
       94          if (prototypeFunction != null) {
       95              for (int i = 0, n = clones.size(); i < n; i++) {
       96                  prototypeFunction.offerStateTo(clones.getQuick(i));
       97              }
       98          }
       99          for (int i = 0, n = clones.size(); i < n; i++) {
      100              clones.getQuick(i).init(symbolTableSource, executionContext);
      101          }
      102      }
