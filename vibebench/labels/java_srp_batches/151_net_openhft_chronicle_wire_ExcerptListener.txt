       43       * Returns a composed ExcerptListener that first accepts excerpts to this ExcerptListener,
       44       * and then accepts excerpts to the {@code after} ExcerptListener.
       45       * If execution of either listener throws an exception, it is relayed to
       46       * the caller of the composed ExcerptListener.
       47       * <p>
       48       * Care should be taken to only create composed listeners that are performant.
       49       *
       50       * @param after the ExcerptListener to accept excerpts after this ExcerptListener
       51       * @return a composed ExcerptListener
       52       * @throws NullPointerException if {@code after} is {@code null }
       53       */
       54      @NotNull

       57          return ((wire, index) -> {
       58              final long readPosition = wire.bytes().readPosition();
       59              this.onExcerpt(wire, index);
       60              // Rewind the wire to allow replaying of messages

       63          });
