       47     *
       48     * <p>The instrumentation names should follow several rules:
       49     *
       50     * <ul>
       51     *   <li>Instrumentation names should consist of hyphen-separated words, e.g. {@code
       52     *       instrumented-library};
       53     *   <li>In general, instrumentation names should be the as close as possible to the gradle module
       54     *       name - which in turn should be as close as possible to the instrumented library name;
       55     *   <li>The main instrumentation name should be the same as the gradle module name, minus the
       56     *       version if it's a part of the module name. When several versions of a library are
       57     *       instrumented they should all share the same main instrumentation name so that it's easy
       58     *       to enable/disable the instrumentation regardless of the runtime library version;
       59     *   <li>If the gradle module has a version as a part of its name, an additional instrumentation
       60     *       name containing the version should be passed, e.g. {@code instrumented-library-1.0}.
       61     * </ul>
       62     */
