       51          Logic:
       52          - If either PROXY_VAR or proxy_var is set in os.environ, set both to the
       53            same value in os.environ.
       54          - Else, if urllib_var is set in urllib.request.getproxies(), use that
       55            value to set PROXY_VAR and proxy_var in os.environ.

       57          Although many of our underlying libraries are case-insensitive when it

       62          proxy environment variables are set if either is set to ensure maximum
       63          compatibility.

       68              proxy = urllib_proxies.get(urllib_var)
