% =====================================================================
% Figure: the measurement pipeline, in three bands.
%   A  CORPUS       how 6,956 pull requests become a balanced sampling frame
%   B  MEASUREMENT  what happens to one pull request
%   C  VALIDATION   two independent axes converging on the report
%
% The two elements that distinguish this design from a conventional mined
% corpus carry the visual weight: the agent x outcome grid in band A, and
% the tier ladder in band B, whose top rung is available only to merged
% pull requests and is therefore why the outcome contrast is tier-matched.
%
% Layout note: band origins and the x positions inside each band are set
% explicitly so that no node can drift into another as text is edited.
% =====================================================================
