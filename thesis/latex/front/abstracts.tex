\flagicon{flag_usa}\quad{\large\bfseries\color{issatblue} Abstract}
\end{center}
\vspace{1pt}
\noindent Autonomous coding agents now author code submitted to real software projects, yet existing
benchmarks measure functional correctness almost exclusively. This thesis measures whether code from
Claude Code, GitHub Copilot and OpenAI Codex follows the five \textsc{solid} principles, across
\textbf{4{,}245 Java pull requests} and \textbf{4{,}946 Python pull
requests}, merged, rejected and open.

Each principle is a deterministic structural proxy whose construct validity is measured:
\textbf{2{,}475 entities} were read and labelled by an independent judge that recorded a reason for
every verdict. Precision ranges from 0.330 to 0.892 in Java and 0.110 to 1.000 in Python.

In both languages change size dominates every principle, roughly doubling the odds of a flag per
doubling of files touched, and the only agent difference found in both is Claude Code's higher rate
on Open/Closed. Most violations predate the agents' changes: the touched code holds 183
refused-bequest violations in Java against 16 pull requests that introduced one, and 176 against
five in Python. Merged and unreviewed Java code look alike; merged Python code is cleaner.

\vspace{2pt}
\noindent\textbf{Keywords:} coding agents, SOLID principles, software architecture, static
analysis, empirical software engineering, Java and Python.

\noindent Les agents de codage autonomes produisent du code soumis \`a de vrais projets logiciels,
mais les r\'ef\'erentiels existants mesurent presque exclusivement la correction fonctionnelle. Cette
th\`ese mesure si le code de Claude Code, GitHub Copilot et OpenAI Codex respecte les cinq principes
\textsc{solid}, sur \textbf{4~245 \emph{pull requests} Java} et
\textbf{4~946 \emph{pull requests} Python}, fusionn\'ees, rejet\'ees et ouvertes.

Chaque principe est un indicateur structurel d\'eterministe dont la validit\'e de construit est
mesur\'ee~: \textbf{2~475 entit\'es} ont \'et\'e lues et annot\'ees par un juge ind\'ependant. La
pr\'ecision varie de 0,330 \`a 0,892 en Java et de 0,110 \`a 1,000 en Python.

Dans les deux langages la taille du changement domine chaque principe, et le seul \'ecart entre
agents retrouv\'e dans les deux est le taux plus \'elev\'e de Claude Code sur Ouvert/Ferm\'e. La
plupart des violations pr\'ec\`edent les changements des agents~: le code touch\'e contient 183 refus
d'h\'eritage en Java contre 16 \emph{pull requests} qui en introduisent un, et 176 contre cinq en
Python. Le code Java fusionn\'e ressemble au code non revu~; le code Python fusionn\'e est plus
propre.
\end{french}
