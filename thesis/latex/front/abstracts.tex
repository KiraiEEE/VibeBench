\begin{Arabic}
\noindent باتت الشفرة الصادرة عن عملاء البرمجة الذاتيين تُقدَّم إلى مشاريع حقيقية، غير أنّ معايير
التقييم الحالية تكاد تقتصر على الصحة الوظيفية، تاركةً جودة العمارة البرمجية دون توصيف. تقيس هذه
الأطروحة مدى التزام الشفرة الصادرة عن \LR{Claude Code} و\LR{GitHub Copilot} و\LR{OpenAI Codex} بمبادئ SOLID
الخمسة، اعتمادًا على 4245 طلب دمج بلغة جافا، مع تكرار كامل للدراسة على 4946 طلب دمج بلغة بايثون،
تشمل المدمجة والمرفوضة والمفتوحة.

واعتُمد لكل مبدأ مؤشرٌ بنيويٌّ حتميٌّ جرى قياس صدقه لا افتراضه: إذ خضعت 2475 حالة لحكم قراءةٍ
مستقلٍّ يسجّل سبب كل حكم. وتراوحت الدقّة بين \textenglish{\arabicfont 0.330} و\textenglish{\arabicfont 0.892} في جافا، وبين \textenglish{\arabicfont 0.110} و\textenglish{\arabicfont 1.000} في بايثون.

وفي اللغتين يطغى حجم التغيير على كل المبادئ، ولا يصمد بعد الضبط سوى فرقٍ واحد بين العملاء، هو
فرق \LR{Claude Code} في مبدأ المفتوح/المغلق. ويتركّز الخلل داخل الوحدة البرمجية الواحدة: ففي مبدأ
ليسكوف 681 مخالفة موجودة مقابل 16 مُدخَلة في جافا، و194 مقابل خمس في بايثون. ولا تكاد طلبات جافا
المدمجة والمرفوضة تختلف بنيويًّا، أمّا في بايثون فالشفرة المدمجة أنظف.
\end{Arabic}

\flagicon{flag_usa}\quad{\large\bfseries\color{issatblue} Abstract}
\end{center}
\vspace{1pt}
\noindent Autonomous coding agents now author code submitted to real software projects, yet
existing benchmarks measure functional correctness almost exclusively. This thesis measures whether
code from Claude Code, GitHub Copilot and OpenAI Codex adheres to the five \textsc{solid}
principles, across \textbf{4{,}245 Java pull requests} and a full replication over \textbf{4{,}946
Python pull requests}, merged, rejected and still open alike.

Each principle is a deterministic structural proxy whose construct validity is measured rather than
assumed: \textbf{2{,}475 entities} were read and labelled by an independent judge that recorded its
reason for every verdict. Precision ranges from 0.330 to 0.892 in Java and from 0.110 to 1.000 in
Python.

In both languages, change size dominates every principle, roughly doubling the odds of a flag per
doubling of the files touched, and the one agent difference that survives adjustment is Claude
Code's on Open/Closed. Risk is concentrated \emph{inside} single units: 681 Liskov violations are
present in the touched Java code against 16 introduced, and 194 against five in Python. Merged and
rejected Java requests are structurally indistinguishable; merged Python code is cleaner.

\vspace{2pt}
\noindent\textbf{Keywords:} coding agents, SOLID principles, software architecture, static
analysis, empirical software engineering, replication.

\begin{french}
\noindent Les agents de codage autonomes produisent du code soumis \`a de vrais projets logiciels,
mais les r\'ef\'erentiels existants mesurent presque exclusivement la correction fonctionnelle.
Cette th\`ese mesure si le code de Claude Code, GitHub Copilot et OpenAI Codex respecte les cinq
principes \textsc{solid}, sur \textbf{4~245 \emph{pull requests} Java} et une r\'eplication
compl\`ete sur \textbf{4~946 \emph{pull requests} Python}, fusionn\'ees, rejet\'ees et encore
ouvertes.

Chaque principe est un indicateur structurel d\'eterministe dont la validit\'e de construit est
mesur\'ee plut\^ot que suppos\'ee~: \textbf{2~475 entit\'es} ont \'et\'e lues et annot\'ees par un
juge ind\'ependant. La pr\'ecision varie de 0,330 \`a 0,892 en Java et de 0,110 \`a 1,000 en Python.

Dans les deux langages, la taille du changement domine chaque principe, et le seul \'ecart entre
agents qui r\'esiste \`a l'ajustement est celui de Claude Code sur Ouvert/Ferm\'e. Le risque se
concentre \emph{\`a l'int\'erieur} des unit\'es~: pour Liskov, 681 violations sont pr\'esentes
contre 16 introduites en Java, et 194 contre cinq en Python. Le code Java fusionn\'e et rejet\'e est
structurellement indiscernable~; le code Python fusionn\'e est plus propre.
\end{french}

\vspace{2pt}
\begin{french}
\noindent\textbf{Mots-cl\'es~:} agents de codage, principes SOLID, architecture logicielle,

\end{french}
