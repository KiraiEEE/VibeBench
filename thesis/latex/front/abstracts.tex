\begin{Arabic}
\noindent باتت الشفرة الصادرة عن عملاء البرمجة الذاتيين تُقدَّم إلى مشاريع حقيقية، غير أنّ معايير
التقييم الحالية تكاد تقتصر على الصحة الوظيفية، تاركةً جودة العمارة البرمجية دون توصيف. تقيس هذه
الأطروحة مدى التزام الشفرة الصادرة عن Claude Code وGitHub Copilot وOpenAI Codex بمبادئ SOLID
الخمسة، اعتمادًا على 4245 طلب دمج بلغة جافا في 1010 مستودعات، تشمل المدمجة والمرفوضة والمفتوحة.

واعتُمد لكل مبدأ مؤشرٌ بنيويٌّ حتميٌّ جرى قياس صدقه لا افتراضه: إذ خضعت 1400 حالة لحكم قراءةٍ
مستقلٍّ يسجّل سبب كل حكم، مع جولة تحقّقٍ خارج العيّنة. وتراوحت الدقّة بين 0.330 و0.890، ونسبة
الاسترجاع بعد ترجيح الطبقات بين 0.352 و1.000.

ويتركّز الخلل داخل الوحدة البرمجية الواحدة: فمن بين نحو 4100 مخالفة لمبدأ المسؤولية الواحدة موجودة
أصلًا في الشفرة المعدَّلة، لم تُدخِل العملاء مخالفةً جديدة إلّا في اثنين إلى أربعة بالمئة من
طلباتها، وفي مبدأ ليسكوف 681 مخالفة موجودة مقابل 16 مُدخَلة. كما لا تكاد الطلبات المدمجة والمرفوضة
تختلف بنيويًّا، ممّا يشير إلى أنّ المراجعة البشرية لا تنتقي على أساس هذه الخصائص.

\flagicon{flag_usa}\quad{\large\bfseries\color{issatblue} Abstract}
\end{center}
\vspace{1pt}
\noindent Autonomous coding agents now author code submitted to real software projects, yet
existing benchmarks measure functional correctness almost exclusively. This thesis measures whether
code from Claude Code, GitHub Copilot and OpenAI Codex adheres to the five \textsc{solid}
principles, across \textbf{4{,}245 Java pull requests in 1{,}010 repositories}, merged, rejected
and still open alike.

Each principle is a deterministic structural proxy whose construct validity is measured rather than
assumed: \textbf{1{,}400 entities} were read and labelled by an independent judge that recorded its
reason for every verdict, including an out-of-sample holdout. Precision ranges from 0.330 to 0.890
and stratum-weighted recall from 0.352 to 1.000.

Risk is concentrated \emph{inside} single units. Of roughly 4{,}100 single-responsibility
violations already present in the code these agents touched, they introduced one in two to four per
cent of their pull requests, and Liskov Substitution shows 681 violations present against 16
introduced. Merged and rejected requests are structurally indistinguishable, which indicates that
human review does not select on these properties.

\vspace{2pt}
\noindent\textbf{Keywords:} coding agents, SOLID principles, software architecture, static
analysis, empirical software engineering.

\begin{french}
\noindent Les agents de codage autonomes produisent du code soumis \`a de vrais projets logiciels,
mais les r\'ef\'erentiels existants mesurent presque exclusivement la correction fonctionnelle.
Cette th\`ese mesure si le code de Claude Code, GitHub Copilot et OpenAI Codex respecte les cinq
principes \textsc{solid}, sur \textbf{4~245 \emph{pull requests} Java r\'eparties sur 1~010
d\'ep\^ots}, fusionn\'ees, rejet\'ees et encore ouvertes.

Chaque principe est un indicateur structurel d\'eterministe dont la validit\'e de construit est
mesur\'ee plut\^ot que suppos\'ee~: \textbf{1~400 entit\'es} ont \'et\'e lues et annot\'ees par un
juge ind\'ependant, avec un \'echantillon de contr\^ole hors \'echantillon. La pr\'ecision varie de
0,330 \`a 0,890 et le rappel pond\'er\'e par strate de 0,352 \`a 1,000.

Le risque se concentre \emph{\`a l'int\'erieur} des unit\'es~: sur environ 4~100 violations du
principe de responsabilit\'e unique d\'ej\`a pr\'esentes dans le code touch\'e, les agents n'en
introduisent que dans deux \`a quatre pour cent de leurs demandes, et pour Liskov 681 violations
sont pr\'esentes contre 16 introduites. Les demandes fusionn\'ees et rejet\'ees sont
structurellement indiscernables.
\end{french}

\vspace{2pt}
\begin{french}
\noindent\textbf{Mots-cl\'es~:} agents de codage, principes SOLID, architecture logicielle,

\end{french}
